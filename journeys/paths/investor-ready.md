# Path: Investor-Ready

**Destination:** You can walk into a pitch with everything an investor expects to see.
**Prerequisites:** All five foundation pills, weighted heaviest on Market and Financials.

## Path-specific pills

- [ ] Pitch deck built (problem, solution, traction, team, ask) — Evidence: the deck
- [ ] Cap table clean and current — Evidence: the cap table
- [ ] Traction metrics defined and tracked — Evidence: metrics dashboard
- [ ] Financial projections, 3–5 years — Evidence: the model
- [ ] Use of funds spelled out — Evidence: allocation breakdown
- [ ] Data room assembled — Evidence: the data room link

## Done looks like

An investor asks "send me the deck and the numbers" and you reply in one message with both.
