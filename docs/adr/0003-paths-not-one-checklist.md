# Paths, not one checklist

"Business ready" means different things to a buyer, a bank, an investor, and a grant-maker — so the app has four paths (sell, loan/financing, investors, grants), not one master checklist. All paths share the five foundation pills; each path then diverges into its own path-specific pills. The user picks a path up front but can switch or pursue two at once; the readiness score is reported per path. We rejected a single universal checklist because it would either be bloated with irrelevant items or too shallow to satisfy any real funder.
