# Proactive by design

BusinessReady nudges, reminds, and celebrates. It speaks first — unlike the personal Journal (ADR-0003), which stays silent unless asked. We chose this deliberately: a readiness coach that waits to be asked fails its job, because the whole point is catching what the owner hasn't thought of yet. Proactivity is bounded: the user controls nudge frequency, and every nudge is either a reminder with a next action or a celebration of progress — never noise.
