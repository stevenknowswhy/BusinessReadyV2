# The have-vs-need ledger is the core data model

Every readiness item in the app is either HAVE or NEED — there is no third state. HAVE requires evidence attached: a document, photo, link, or record. A claim without evidence doesn't count, because lenders, buyers, and grant-makers ask for proof, not promises. NEED always pairs with a concrete next action, so a gap is never just a gap — it's a step. The readiness score (HAVE ÷ total items) derives entirely from this ledger, which makes the score honest: it moves only when reality moves.
