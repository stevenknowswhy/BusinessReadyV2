# Open-a-business path

A fifth path, "Open a business," joins sell, loan, investors, and grants (extends ADR-0003's four paths to five).

It is a very simple multi-step form — one question per step, minimal fields. The first question branches the journey: online-only vs. brick-and-mortar. Online-only leads to a lighter pill set (business registration, tax basics, core compliance); brick-and-mortar leads to the fuller compliance surface (permits, zoning/planning, signage, health permits, labor ordinances).

Rationale: opening is the natural front door — the SF startup matrix already distinguishes online-only from physical retail on compliance burden, and the HAVE / NEED / DESIRABLE ledger, evidence rules, and readiness score apply identically. The branch keeps the form simple while routing each business to the pill set that matches its real obligations.
